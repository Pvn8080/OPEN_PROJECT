OPEN PROJECT - INTERACTIVE LOCAL PREVIEW

1. Extract this ZIP into a folder on your computer.
2. Open Open-Project.html in a desktop browser.
3. The sample planner opens automatically. Click task names to edit,
   drag Gantt bars to reschedule, and use Resources and Set baseline.

No installation, server or API key is required for manual planning.
Changes are saved in this browser. Keep the HTML file in the same
location and use the same browser. Private browsing and clearing browser
data may remove saved work. Use Export backup to keep a JSON copy.

This local preview does not provide live AI, accounts or team sharing.
Those features require the server version. No project data is sent to
a service by this local preview.
